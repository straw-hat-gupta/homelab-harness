# Reliability requirements

> **Status: requirement ledger; only parts of 1A have automated fixture evidence. No runtime/lab acceptance is complete.** Evidence from the retired application is preserved in the snapshot and is not current coverage. See [ADR-0013](../adr/0013-claude-fixture-proof.md) for the selected proof technology; direct typed validation and a central standard-library Settings object replace the previous framework assumptions. R-01–R-46 retain their identity/intent; store/command assumptions are narrowed to the newly selected boundary. R-47 onward cover the managed-runtime design.

A requirement becomes applicable when its behavior is enabled. Deferral does not permit an unsafe substitute. Fill evidence with an actual test/acceptance reference only when implemented; no existing test pointer is a claim that removed code remains active. See [testing/evals](testing-and-evals.md) and [Stage 1](../stage-1.md).
